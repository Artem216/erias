# Задания ЭРИАС 1–4

Каждое задание находится в отдельной папке и запускается только средствами
стандартной библиотеки Python.

- [Задание 1](task_01/README.md) — косинусное сходство товаров и пользователей.
- [Задание 2](task_02/README.md) — агломеративная кластеризация.
- [Задание 3](task_03/README.md) — фильтрация и разреженное хранение матрицы.
- [Задание 4](task_04/README.md) — user-based рекомендации.

Запуск любого решения:

```bash
python3 task_01/solution.py
```

В каждой папке есть снимки исходного кода и результата выполнения.
